Этап 2. Бэкенд работает, все критерии выполнены

Запускал сервер с настоящим WHOIS, проверял руками. Тесты 40 из 40 (python -m pytest), сеть им не нужна.

Проверка по критериям
- uvicorn backend.main:app запускается, /docs отдаёт 200, /health отвечает {"status":"ok"}
- kaspi.kz: risk 0, в белом списке
- http://192.168.1.1/login@verify: risk 92, phishing
- kaspi-login.xyz: risk 96, причина "Домен похож на kaspi.kz: содержит kaspi"
- без WHOIS ответ 11-30 мс (нужно < 200), из кэша почти 0
- с WHOIS 0.1-2.5 с (нужно < 3), таймаут 2.5 с
- tests/test_reputation.py проходит без сети

Полный запрос со страницей kaspi-verify.xyz/login: risk 95, ML 1.0, репутация 0.9, контент 0.9. Пять причин: бренд, форма на чужой домен, бренд в заголовке, зона .xyz, слова login и verify.

Код в backend/: main.py, ml_model.py, reputation.py, content.py, scorer.py, brands.py, whitelist.py. Там же .env.example и requirements.txt с версиями.

Что пришлось поменятьм
- WHOIS для .kz. python-whois не понимает дату регистрации в ответах KazNIC, для всех .kz было "Не удалось получить WHOIS". Дописал разбор даты из сырого ответа, теперь работает.
- Тайпосквоттинг. Сравниваю с ключевыми словами брендов, а не со всеми официальными доменами, иначе life.com считался подделкой live.com. Для коротких брендов (5 букв) порог 1 правка и первая буква должна совпадать. Цифры вместо букв тоже ловит: paypa1, micros0ft.
- Сайт по IP. Репутация даёт 0.8, иначе WHOIS для IP всегда падал и было бы только 0.3.
- Кэш. Храню только тяжёлую часть (ML и репутацию) по ключу хост + путь. Контент считается каждый раз, чтобы первая проверка без page не мешала следующей с данными страницы.
- WHOIS_ENABLED=0 в .env выключает WHOIS. Так работают тесты, и для офлайн-демо удобно.
- В логах и кэше URL без query-параметров.

Ограничения
- Тайпосквоттинг даёт только "подозрительный": kaspl.kz получает 45. ML тут ничего не видит, а вес репутации без данных страницы 0.4. На реальной странице с паролем и брендом в заголовке риск будет выше.
- Ключа Google Safe Browsing нет, проверка пропускается. Чтобы включить: скопировать backend/.env.example в backend/.env и вписать ключ.
